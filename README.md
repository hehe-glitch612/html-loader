# HTML Loader

A simple HTML loader that serves your HTML files on a separate port using Express.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/hehe-glitch612/html-loader.git
cd html-loader
```

2. Install dependencies:
```bash
npm install
```

## Running

Start the server:
```bash
npm start
```

The server will run at `http://localhost:3000`

## Features

- Serves HTML files on port 3000
- Fast and lightweight using Express
- Static file serving for CSS, JS, and images
- Easy to customize

## Customization

Edit `public/index.html` to add your own HTML content, and `server.js` to change the port or add more routes.
